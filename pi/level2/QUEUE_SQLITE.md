# Level 2 transactional queue candidate
SQLite WAL is a local-host transactional task queue for experiment metadata; **not a distributed cloud service**. It does not run commands, Claude, or Codex. A per-task database transaction serializes simultaneous claims. Leases expire and rejected tasks stop after two attempts. Cost guard rejects all provider calls. Review identity is a string placeholder only, not authenticated independence. The acceptance criteria and actual source diffs must be checked by a separate trusted verifier before any real use. This prototype is sandbox/CI-only, with no production credentials. Run with `python3 pi/level2/queue-sqlite-test.py`; do not enable real provider or actuator integrations.
